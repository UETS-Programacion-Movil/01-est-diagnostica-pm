# Semana 01 — Evaluación Diagnóstica (PM)

Programación Móvil · 3.° Bachillerato Técnico UETS (2026–2027).

Vas a resolver 4 bloques prácticos (lógica y POO en Java, HTML5 + CSS3, JavaScript y DOM, depuración web con reporte) y a grabar un screencast de 3 a 5 minutos explicando tu solución.

## Trabaja en Codespaces

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/UETS-Programacion-Movil/01-est-diagnostica-pm)

1. Haz **Fork** de este repositorio a tu cuenta.
2. Abre tu fork con **Codespaces** (botón verde `<> Code` → pestaña `Codespaces` → `Create codespace on main`).
3. Instala dependencias: `pnpm install`.
4. Corre las pruebas: `pnpm test`.
5. Abre el **Pull Request desde Codespaces** contra `main` del repositorio oficial.

## Entrega

- **Video Screencast (3 a 5 min):** rostro visible en cámara, voz explicando tu solución y demo de `pnpm test` en verde. Pega el enlace en la descripción de tu Pull Request.
- Checklist:
  - [ ] `pnpm test` pasa al 100 %.
  - [ ] Video con cámara y voz, enlace pegado en el PR.
  - [ ] No modificaste archivos de `tests/`.
